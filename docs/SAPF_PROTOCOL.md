# SAPF 机制实验协议

本协议对应 sapf_google_holdout_v1；研究目标是检验历史归一化、相似性与可靠性机制，尚不代表完整深度 SAPF 或独立算力中心泛化已成立。代码基准为 bc6a439，新分支 research/sapf-v1。

## 1. 研究问题与先验限制

原三域 pilot 的 24h 多源 Ridge 平均 MAPE 为 2.8084%，前三天同刻均值为 2.3608%；多源训练不是自然优于历史基线。原方案存在目标数少、单域尺度影响、少量源训练窗口、没有独立目标验证域、7d 无可用独立开发窗口等限制。原始结果仅作研究动机，归档保留，不与新域集合直接混排。

本轮问题是：幅值差异是否主导迁移误差；日/周周期、波动、趋势和爬坡差异能否预测迁移收益；仅凭起报前历史与独立验证经验，能否可靠选择源域、改善最差域并减少负迁移。相关性只描述关系，不证明某种差异导致负迁移。

## 2. 固定角色与时间

在计算新测试误差前，以原生 3/3 有效样本和无歧义映射筛出完整 PDU，排除 MVPP 及此前的 cella_pdu10、cellb_pdu11、cellc_pdu40。每个 cell 内按自然 PDU 编号排序，位置模 3 依次为源/验证/测试，得到 14/11/10 个互不重叠域。完整清单、候选网格和模型源码哈希先写入 preregistration.json，运行还保存 predeclared-plan.json。

质量筛选使用全期掩码，但不使用数值误差；结论限定于完整观测。角色隔离是电力域级，源与目标可以同 cell；这不是独立设施留出。Google 历史发布及旧模型结果已被研究过，新划分不被描述为新采集的未触碰数据。

## 3. 递进机制与预先固定参数

所有 Ridge 的 alpha=100，不依据新测试调参。基础对照包括前一天同刻、前三天均值、14 个原始单源、原始多源、14 个归一化单源和归一化多源；另加入相似性选择及 SAPF。终端仅显示预先固定的首个单源，完整单源曲线仍全部归档。

归一化对每个窗口计算过去 14 天均值 μ 和尺度 σ=max(历史标准差,0.01|μ|,1e-6)，输入和源训练标签均用 (y−μ)/σ；预测恢复 μ+σ×ŷ。目标域只贡献当前历史窗口统计，不拟合全局模型/标准化或校准参数。未来真实值或质量标记不进入预测。

负荷签名含对数水平、变异系数、日/周相关、相对日趋势、平均绝对爬坡、爬坡标准差和日内轮廓幅度。源签名由允许源训练样本截至截止的观测构造；特征尺度仅用源域的 IQR/标准差拟合。相似性选择在 shape 与 level_shape 两组特征、top-k={1,3,7}、温度={0.5,1,2} 中用独立验证域选择。

SAPF 先在独立验证域计算每个归一化源专家的平均 MAPE，可靠性与该误差的倒数成比例，并裁剪到预定范围。混合权重同时考虑距离和可靠性。每个目标起报的迁移门为 γ/(1+最近源距离)，其余权重分配给固定的前三天同刻均值。γ={0,0.25,0.5,0.75,1}，可靠性幂={0,1}；γ=0 允许完全放弃外部知识。最终选择准则为验证域平均 MAPE + 0.1 × 最差域 MAPE，同分优先更弱迁移与更少源域。

这是可审计的选择性迁移原型，使用人工历史签名及 Ridge 专家；没有宣称这些组件等于已经完成共享深度编码器、任务预训练或新理论证明。

## 4. 防泄漏与冻结

先完成全部任务的源开发拟合、独立验证校准，再按固定参数最终拟合源域。模型、归一化配置、签名尺度、源池、可靠性及门控候选选择一起保存。全部任务完成后写 frozen-before-test.json，再写带其哈希和时间的 test-start.json，之后才构造测试 batch。

预测可以按起报前目标历史更新签名和局部尺度，不能更新源专家、可靠性、参数或源池。最终源码、模型哈希和选择记录保留。验证期 SAPF 评价参与候选选择，是选择期成绩；只将独立测试期结果用于本轮效果陈述。

数据使用策略禁止 Eagle 的任何观测/标签参加训练、校准、验证和策略设计；只允许最终测试时的起报前历史。ESIF 是另一份设施分项数据，不能改名充当 Eagle。当前 Eagle 未在本地定位，未读取其数据。

## 5. 评价与分析

唯一指标函数为 forecast_metrics，回测与日均仍共用 backtest/score_predictions。每域/任务保留曲线与日均 MAPE、WAPE、RMSE、MAE、样本数、逐起报、提前量、目标日和非重叠记录。MAPE 阈值固定 1e-8；跨域取域等权平均和最差值，不将不同单位、计量边界或新旧域集合混排。

比较差值为同一目标、起报、标签和可用输入条件下的 MAPE(方法)−MAPE(固定基线)，正值超过 1e-10 记变差；相对变化为差值/基线×100。分别报告：原始增加源域、归一化增加源域、归一化相对原始多源、相似性相对归一化多源、SAPF 相对归一化多源及本地历史。SAPF 与本地基线的差值称性能比较，不把它冒充纯粹加入某个源造成的因果负迁移。

历史签名和源→目标误差按验证/测试分别保存，报告 Pearson/Spearman 描述性相关；重复源、目标、起报不视作独立样本，不报未经适当聚类或独立数据支持的显著性。测试后的相关分析不得返回修改本轮参数，后续机制设计须重新预注册并获得新的独立评价。
