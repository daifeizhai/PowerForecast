# 模型输入输出统一约束

## 一、模型输入

| 输入类别       | 具体内容                         | 是否必需 | 说明                                     |
| -------------- | -------------------------------- | -------- | ---------------------------------------- |
| 历史负荷       | 数据中心历史总有功功率           | 核心输入 | 优先使用实测功率，其他预测标签须注明性质 |
| 算力任务特征   | 任务数量、任务类型、任务并发量等 | 可选     | 体现算力活动对负荷的影响                 |
| 资源利用特征   | CPU/GPU 利用率、资源占用等       | 可选     | 分析资源运行状态与功耗的关系             |
| IT 设备特征    | 服务器功率、IT 总功率等          | 可选     | 描述计算设备的用电特性                   |
| 制冷及辅助特征 | 制冷功率、辅助设备功率、PUE 等   | 可选     | 反映 IT 与辅助负荷的关联                 |
| 环境特征       | 室外温度、湿度等                 | 可选     | 反映环境对制冷负荷的影响                 |
| 时间特征       | 时刻、星期、工作日等             | 基础特征 | 描述负荷周期变化规律                     |

## 二、模型输出

**核心预测对象：数据中心整体总有功功率，单位为 kW（千瓦）。**

### 2.1 负荷预测任务

| 任务类型 | 预测时长 | 输出点数 | 输出形式       | 优先级   |
| -------- | -------- | -------- | -------------- | -------- |
| 短期预测 | 4 小时   | 16 点    | 功率曲线（kW） | **优先** |
| 短期预测 | 8 小时   | 32 点    | 功率曲线（kW） | 次优先   |
| 短期预测 | 24 小时  | 96 点    | 功率曲线（kW） | **优先** |
| 中期预测 | 3 天     | 288 点   | 功率曲线（kW） | **优先** |
| 中期预测 | 7 天     | 672 点   | 功率曲线（kW） | **优先** |

### 2.2 辅助输出与评价指标

| 输出类别     | 具体内容                   | 输出形式         | 优先级         |
| ------------ | -------------------------- | ---------------- | -------------- |
| 统计结果     | 日均功率、峰值功率等       | 数值及图表       | 辅助输出       |
| 核心评价指标 | MAPE（平均绝对百分比误差） | 百分比（%）      | **最高优先级** |
| 辅助评价指标 | WAPE、RMSE、MAE            | 误差指标与对比表 | 辅助评价       |
| 可视化结果   | 真实负荷与预测负荷对比     | 预测曲线及误差图 | 基础输出       |

## 三、统一技术约束

| 约束项目     | 统一要求                                                   |
| ------------ | ---------------------------------------------------------- |
| 时间分辨率   | 15 分钟，每天 96 点                                        |
| 历史输入长度 | 默认过去 14 天，共 1344 点                                 |
| 核心预测对象 | 数据中心整体总有功功率                                     |
| 预测目标单位 | kW（千瓦）；电量统计使用 kWh（千瓦时）                     |
| 预测任务     | 短期：4、8、24 小时；中期：3、7 天                         |
| 优先预测任务 | **4 小时、24 小时、3 天、7 天**                            |
| 模型输入模式 | 支持单变量基础预测与多变量增强预测                         |
| 数据集适配   | 允许不同数据集使用不同辅助特征及独立实验划分协议           |
| 数据真实性   | 严格区分实测功率、分项派生功率、理论估算功率及功率利用率   |
| 防止数据泄漏 | 仅使用起报时刻已知的信息，不使用未来真实观测数据           |
| 核心评价指标 | **MAPE**，作为模型选择与性能评价的首要依据                 |
| 辅助评价指标 | WAPE、RMSE、MAE                                            |
| 预测精度目标 | 以 MAPE ≤ 5%（准确率 ≥ 95%）为当前研究目标；96% 要求待确认 |
| 模型选择依据 | 主要依据验证集 MAPE，最终在独立测试集评价                  |
| 模型适应性   | 支持跨数据中心迁移，尽量减少人工调参和部署成本             |
| 实验可复现性 | 统一模型接口、评价方式和输出格式，保留实验配置及结果       |

**总体原则：** 以算力中心负荷特性及算电关联规律为研究基础，构建机理认知引导的数据驱动预测方法。统一模型输入输出接口，优先开展未来 4 小时、24 小时、3 天和 7 天的负荷预测，以 MAPE 为核心评价指标，兼顾预测精度、跨场景适应性、可解释性与部署便利性。

对于缺少实测总功率的数据集，可开展利用率预测或理论估算功率预测，但须明确标注预测对象及单位，不得将其预测精度直接等同于真实总表功率预测精度。
