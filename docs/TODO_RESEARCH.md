## 2. 未来研究模块的入口与约束

### 2.1 `resource_pretrain`（B 路径，无标签）

- 入口：`src/models/resource_encoder.py`、`BaseResourceEncoder.pretrain(batches: Iterable[PretrainBatch])`；
- 约束：输入**不含任何功率标签**；不同源 `F` 可不同；可分批进入编码器；共享编码器必须依赖显式的特征语义注册表/掩码，不能按原始列序号决定语义；
- 缺失字段用 mask 表达，不把"缺失"编码成"真实测得 0"；
- 事例后生命周期统计（整段均值/最大值）不能伪装成事件发生前的时序观测；只有事件级表格、无合法采样序列的源只登记为 `pretrain_candidate`，不强制生成假的 15min `PretrainBatch`；
- 待研究：异构字段的共享表示、跨源归一化、掩码自监督目标、外部源与目标域的时间隔离。

### 2.2 `target_mapping`（C 路径，目标域有监督）

- 入口：`src/models/target_mapping.py`、`BaseTargetMapper.fit(batch, historic_repr)`；
- 约束：只使用目标域**训练截止/起报前许可**的历史指标与功率；输入表示只能来自相应时刻已知历史，不得用整个未来序列编码后再喂给映射；
- 与无标签源预训练严格分离（不同入口、不同批次类型）；
- 待研究：映射函数族（线性/树/小型网络）、与主路径的残差结构、异常工况下的稳健性。

### 2.3 `fusion`（D 路径，未来研究）

- 入口：`src/models/fusion.py`、`BaseFusion.predict(primary_kw, auxiliary_kw, inputs)`；
- 约束：主路径（纯历史功率）必须始终可独立输出完整预测；融合只能在此之后产生候选/校正量；
- 融合方式、融合系数、动态门控、损失函数**全部未定**；不得用固定权重或 `0*aux` 假装验证过融合；
- 只有明确实现、完成训练/选择并冻结后，才允许加入正式模型注册表；
- 待研究：门控信号、训练目标（点误差 vs 形状）、跨场景稳定性、可解释性。

## 3. 真实数据接入的阻断点（按来源）

| 来源 | 阻断原因 | 解除条件 |
|---|---|---|
| Google Data Center PowerData 2019 | 只有相对功率/利用率面板，非设施总表 kW；时区/频率未核验 | 明确代理任务定义 + 容量标定来源，且**不得**改名成 kW |
| Alibaba Cluster Trace GPU v2020 | 无 kW；机器统计与任务生命周期统计不等于 15min 实时观测 | 仅作无标签预训练语料，登记原生频率与可用时刻 |
| M100 ExaData | 节点级功率，非设施级；频率/可用性待审计 | W→kW 换算并**显式命名节点级辅助任务**，仅用于节点级评估 |
| NLR ESIF 五分项 | 分项计量边界/覆盖/单位/时区待核验；分项和 ≠ 独立设施总表 | 完成边界审计，明确 `component_sum` 语义与覆盖完整性 |
| UCC 2023 / NLR Eagle | 尚未审计，不按名称猜测频率/功率级别 | 元数据审计；若预留 final-holdout，须显式保留禁用资格 |

**当前结论**：本轮**没有任何真实来源**被判定可以产出正式设施 kW 结果；`configs/datasets/registry.yaml` 把它们全部登记为 `candidate` / `unverified` 并给出阻断原因。

## 4. 方法学待决事项

1. **正式 4h / 8h / 3d 协议**：起报日集合、步长、是否非重叠、与 24h/7d 的可比性；
2. **7d 重叠的评价口径**：逐起报主指标 vs 唯一时间戳去重描述统计的并列报告方式；
3. **训练数据量 vs 历史长度的分离**：多步监督模型需要多少历史、多少次起报、如何在不泄漏的前提下扩样；
4. **LightGBM 类表格模型在 D14 截止前的合法特征/样本设计**（lag 结构、逐步展开），本轮只保留可行性检查；
5. **超参数选择的独立性**：开发阶段的标签重叠如何避免"用最终拟合过的标签做独立验证"；
6. **异常工况与钳制策略**：非负截断何时允许、如何记录、如何避免掩盖模型发散；
7. **合成数据的边界**：合成结果只能做工程验证，不能进入真实排行榜；未来是否需要更接近真实统计特性的仿真器。

## 5. 遗留风险

- **真实设施总表功率来源**仍是核心风险：没有它，主任务无法产出正式结果；
- **时区/可用性校核**：多个公开源时区未核验，跨源时间对齐存在错位风险；
- **异构字段可比性**：即使规范名相同，采样与统计语义仍可能不同，共享表示可能不具物理意义；
- **字段语义漂移**：同名但不同单位/统计的历史数据若被合并，会静默污染训练；
- **数据体量与存储**：本地 `data/raw/` 与 `results/` 已有 10 GB 级历史资产，未来任何清理都必须走显式路径清单；
- **可复现性**：随机源尚未引入深度模型；未来引入 GPU 训练后需固定更多随机性（cuDNN、分布式种子等）。
