# M100 跨节点实验：冻结协议

本协议在首轮 M100 预测误差访问之前固定。任务由统一入口 `scripts/run_experiment.py --config configs/sapf_m100.yaml` 执行，遵循公共窗口、评分、冻结和结果保存流程。数据适配不代表跨数据中心泛化已得到验证。

## 数据与样本

- 数据来自已核验官方 SHA-256 的 `0.tar`、`1.tar`，共 33 个节点。专用宽表适配器读取 `timestamp` 和 `total_power_avg`，直接 W→kW；不重复聚合、不要求每个已聚合点含 45 条记录、不插值、不把 GPU/CPU 分项功率改称节点总功率。
- 缺值、无穷、负功率和重复时间键保留为不可用标签；非 UTC 或非 15 分钟对齐时间戳拒绝接入。只使用目标历史和已知相对日/周相位；同槽的 total_power_min/max/std、温度、状态和未来资源统计均不作为未来已知特征。
- 依据前一阶段 33 节点数据质量审计，最长共同有效区间可取 60 个完整 UTC 日。固定公开时间标签区间为 **[2021-04-23 00:00, 2021-06-22 00:00)**，每节点 5,760 个点。区间筛选只用可用性掩码，不按功率幅度、预测误差或模型表现挑选；此实验条件于完整观测，不能声称代表全部缺失时段的线上效果。
- 底层聚合左/右边界和原始计数没有在本次得到恢复。保守规定历史槽的可用性上界为公开时间标签加 15 分钟，必须不晚于起报时刻；假定没有额外上报延迟。不读取起报槽及以后的观测作为输入，保留公开时间标签，不伪造计量区间元数据。
- 历史为 **14 天 / 1344 点**；24h 和 3d 分别为 **96 / 288 点**，均按日滚动起报。不同节点不拼接，任何不完整窗口都不能静默补齐或替换。

## 节点与时间隔离

在每个机架内部按节点整数编号升序，以位置模 3 分别赋予源、验证、测试角色，最终为 **12 / 11 / 10 个节点**。完整 ID 固定在 [sapf_m100.yaml](../configs/sapf_m100.yaml)。同一物理节点只能有一个角色，33 个节点必须全部有角色；两个机架在各角色中均有代表。本实验不是留机架，更不是留数据中心。

Dk 表示已观测前 k 个完整协议日，标签起点为 anchor + k 天。

| 项目 | 24h | 3d |
| --- | --- | --- |
| 源域开发标签截止 | D30 | D30 |
| 开发训练起报 | D14—D29，16/节点 | D14—D27，14/节点 |
| 独立验证域起报 | D30—D36，7/节点 | D30—D36，7/节点 |
| 验证窗口数 | 77 | 77 |
| 源域最终标签截止 | D40 | D40 |
| 最终训练起报 | D14—D39，26/节点 | D14—D37，24/节点 |
| 最终训练窗口数 | 312 | 288 |
| 测试域起报 | D40—D59，20/节点 | D40—D57，18/节点 |
| 测试窗口数 / 曲线点数 | 200 / 19,200 | 180 / 51,840 |
| 3d 非重叠检查 | 不适用 | D40/43/46/49/52/55，共60窗口 |

源域拟合先截止 D30，独立验证域选择设置后，源域可按同一池扩大至 D40 重拟合；验证域和测试域均不进入模型参数、输入标准化器或源特征尺度拟合。两个任务和全部方法的最终状态一并保存、哈希和冻结后，才创建并评分测试窗口。滚动推理允许使用测试节点起报时已观测的 14 天历史，但不会重新拟合、校准、选种子或根据测试误差改变门控。

数据质量审计此前已读取这些文件；本次“测试前冻结”指预测实验及参数选择边界，不表示这些数据此前从未被看过。NLR Eagle 仍整体封存，本次不会打开。

## 主比较与独立消融

主比较为前一天同刻、前三天同刻均值、原始多源 Ridge、历史窗口归一化 Ridge、相似性选择和完整 SAPF。另保存每个源节点的原始/归一化单源 Ridge，终端展示预定首个源节点，绝不取测试最优单源。

Ridge 固定 alpha=100，与上一轮 Google 保持一致。SAPF 的 top-k=[1,3,7]、温度=[0.5,1,2]、特征组=[shape,level_shape]、迁移强度=[0,.25,.5,.75,1]、可靠性幂=[0,1] 均沿用此前候选集；只在 11 个独立验证节点上按“等域平均 MAPE + 0.1 × 最差域 MAPE”选择。参数、归一化下限及所有默认方法见 [m100_models.yaml](../configs/m100_models.yaml)。不把验证期选择分数当无偏泛化成绩。

完整 SAPF 选定验证参数后，对每个任务建立以下单机制关闭版本。**所有版本继承完整 SAPF 的 top-k、温度、特征组、迁移强度、可靠性向量及相同训练样本；不为消融重新搜索参数。**

| 消融 | 唯一干预 | 保持的其他机制 |
| --- | --- | --- |
| sapf_no_normalization | 各源专家在原始 kW 上拟合/推理，不做窗口归一化与尺度恢复 | 源签名、已选路由权重、验证可靠性和历史门控均继承完整模型 |
| sapf_no_selection | 所有源专家等权，不做 top-k/相似性/可靠性路由 | 归一化专家、完整模型的迁移强度及距离置信度回退保持 |
| sapf_no_fallback | 迁移门控强制为 1，关闭前三天同刻均值混合 | 已选源、相似性权重、可靠性和归一化专家保持 |
| sapf_no_reliability | 已选路由中的可靠性幂强制为 0 | 相似性 top-k/温度、归一化和历史门控保持 |

这些是条件于完整模型选择的机制干预，不能冒称各消融模型已获得独立最优参数。关闭归一化时也不重估可靠性向量，避免连带改变另一个机制；归一化的整体建模收益同时用原始/归一化多源 Ridge 与全部单源配对评估。关闭源选择时距离置信度仍属于保持不变的历史回退机制，不将其暗中同时关闭。

完整模型与四个消融均保存独立状态，并验证训练池、验证参数、可靠性向量、最终起报及模型恢复的一致性。

## 指标与负迁移口径

公共函数输出曲线/日均 MAPE、WAPE、RMSE、MAE、样本数及基线降低率；RMSE/MAE 单位为 kW。主结果按 10 个测试节点等权平均，最差域是节点 MAPE 最大值，不按点数池化替代。

“负迁移比例”的主口径为：同一测试节点、相同起报和标签上，训练模型 MAPE 比固定前三天同刻均值差的节点数 / 10；差值容差为 1e-10 个百分点。它是相对无训练本地历史规则的性能代理，不是加入某个源的因果证明。

另行报告相对原始多源、归一化多源的变差节点比例；以及增加源节点相对每个固定单源的源→目标配对劣化比例（12×10=120 配对/任务）。独立消融报告“关闭机制后的 MAPE 变化”和“关闭后更差节点数”，不把不同参考下的比例混成一个负迁移减少率。

3d 日起报高度重叠，补充每三天起报的非重叠曲线指标。此补充不等于独立时间样本，单节点/同机架相关性也仍存在。

## 与 Google 对照的限制

Google 使用 31 天、电力域利用率、14/11/10 域；本次 M100 使用 60 天、节点 kW、12/11/10 节点。训练窗口数、设备和观测目标不同，不能把 MAPE 高低直接归因于数据集或宣称跨数据集泛化；只对照“单源归一化是否有益、多源归一化是否有益、选择是否改善最差节点、历史回退是否贡献收益”等机制结论。

下一阶段仍需独立 UCC 跨数据集协议和封存的 NLR Eagle 最终验证。本次不读取 UCC/Eagle、不训练共享深度编码，也不将同中心跨节点结果改写为跨中心或设施总表精度。
