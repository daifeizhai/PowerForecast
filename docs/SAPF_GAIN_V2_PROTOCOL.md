本协议执行[四周任务](SAPF当前研究成果评估与下一阶段研究计划.md)，范围为统一契约、四种收益目标、四种表示、完整融合对照、4h补齐和统计评价。第三独立数据集、深度编码器、Alibaba预训练及Eagle最终验证属于后续阶段，本轮不启动。入口仍为 `scripts/run_experiment.py --config configs/sapf_gain_v2.yaml`。

原工作区已在`research/sapf-v1`保存为基线提交`f89dc7d`，本地标签`sapf-gain-v1-frozen-20261026`；从该状态建立`research/sapf-gain-v2`。旧源码、预测、模型和证据不覆盖。新计算源码、配置、质量审计和本协议在真实预测前写入预注册JSON；源组、全部方法、两个采样协议和三个时长统一冻结后，才能访问任何新测试误差。

## 4. 四种收益目标与共同决策

令本地前三天同刻均值为l，专家为e，当前预测为c，损失L为曲线MAPE，固定一步融合系数α=0.5。

| 目标 | 监督定义 |
| --- | --- |
| single | L(y,l)−L(y,e)：单专家独立收益 |
| fixed | L(y,l)−L(y,0.5l+0.5e)：固定融合收益，与当前c无关 |
| marginal | L(y,c)−L(y,0.5c+0.5e)：当前集合上的边际收益 |
| rank | 同一伪目标/起报/时长/当前c下，两个候选的边际收益谁更大；每个候选取两个循环相邻对手，并加入交换方向的样本 |

四种方法统一使用Level–Shape源专家，统一最多两步、每步50%融合、源不重复及相同候选阈值；区别是学习目标。训练第一步c=l，第二步c=0.5l+0.5e_k。**第一步fixed与marginal数学上相同，代码必须核对相等，不能将相同标签包装成两个独立创新。**第二步才检验对已引入知识的互补判断。

共同输入47维：原42维历史/源内性能/预测分歧特征，加阶段、当前预测相对本地及专家的分歧/水平/波动5维。域ID和数据集名不是数值特征。数值标签不进入`predict`接口。

点式回归器与负迁移分类器、成对排序分类器均固定ExtraTrees：64棵，深度6，叶样本下限20，种子42，单线程；风险分类器balanced。拟合权重按伪目标等权，不能把相关源配对当独立实验。rank通过候选之间平均胜率得分，经独立校准映射成预计边际收益；原始胜率不是MAPE百分点。

收益尺度用独立校准节点的Ridge仿射映射（alpha=10）校准。single/fixed仍校准各自目标，marginal/rank校准边际目标。风险用logit上的sigmoid校准，校准标签共同定义为负边际融合收益；再向训练域边际负迁移基率收缩。收缩比例[0,0.5,1]仅按留一校准节点的Brier选择，最后在全部校准身份拟合映射；不接触策略验证或测试标签。

每步从未选源中要求预计收益>margin、风险≤上限，选预计收益最大的一个源；无合格源则停止。margin=[0,0.1,0.5]百分点、风险上限=[0.5,0.75,1]，只在独立策略验证节点按等权平均MAPE+0.1×最差节点MAPE选择。平分时优先更高margin、更低风险上限。停止在第0步必须与本地完全一致。

主方法预先固定为`gain_v2_marginal`，**不按测试成绩在四种目标或四种表示中另选“最终SAPF”**。风险可校准性及收益门槛是否成功均由新测试判断；建议成功门槛是验收标准，不是一定会达到的结果。

## 5. 四种表示与完整对照

四种表示都使用相同Ridge alpha=100和源拟合StandardScaler：raw原始历史→原始标签；zscore局部归一化历史→归一化标签；level_shape拼接完整raw滞后与z-score滞后两个通道；scale_metadata为z-score滞后加历史μ/σ。后三者只用该窗口历史恢复尺度；不全局拟合目标测试统计。双通道的共线性由Ridge正则处理。本轮不增加MLP或Transformer。

四种表示分别保存多源联合模型、单源专家→目标矩阵。收益策略及固定混合使用同一Level–Shape专家池；原SAPF保留此前z-score相似性/验证可靠性机制并在新开发角色上重新选择，跨机制比较不能只归因于标签变化。

默认17个可部署对照为：前一天同刻、前三天同刻均值、四种表示多源Ridge、等权纯迁移、25/50/75%固定混合、当前SAPF、四种收益目标、强制迁移和关闭校准。两个干预都继承边际方法的同一源池、学习器和验证阈值，仅分别取消拒绝或取消校准，不能重新调参。

事后`oracle_posthoc`不进入模型工厂、训练、校准、选参或任何部署决策。测试完成后才用真值逐起报选择预先固定的有限集合：全部冻结预测、本地两基线、每个Level–Shape专家与本地的α=[0,0.25,0.5,0.75,1]融合，以及两名不同专家的两步50%融合。它包含主方法的可能动作，代表有限集合的事后潜力，不是任意模型的理论最优。

## 6. 指标、统计与判定

公共指标MAPE/WAPE/RMSE/MAE，RMSE/MAE为kW；Google单独为利用率契约，不并入本轮kW成绩。MAPE阈值1e-8，计数与排除数保留。日均只适用于完整24h/3d，4h的daily_mean必须为N/A、n=0，不能把4h均值写成日均。

同时报告节点等权平均/最差MAPE、比本地两基线与固定50%混合更差的节点比例、零迁移率、成功迁移率（全部/发生迁移起报两个分母）、正边际收益配对精确率/召回率、被选正收益精确率/召回率和机会捕获率。四种收益模型风险评价统一在第0步全部源专家配对的实际边际收益上进行，避免只报被选专家或不同标签的基率。报告原始与校准Brier、源训练边际基率常数Brier、AUROC和收益MAE。

3d主表增加非重叠D54/D57/D60，滚动表完整保留。主统计预先比较marginal对前三天均值、前一天同刻、固定50%混合；域级配对ΔMAPE<0表示改善。种子20261026，2000次目标节点cluster bootstrap及节点内长度3起报的循环块bootstrap，给均值、中位数、95%百分位区间和改善域比例。非重叠3d另给同口径统计。

滚动36项与非重叠3d的12项比较组成每类bootstrap的48项Holm族；域级DM辅助检验组成单独族，未满足样本量的预声明检验按p=1留在校正族。DM使用逐起报APE差、Bartlett-HAC，滞后max(2,ceil(时长天数)−1)，起报少于8时N/A。当前3d只有7个滚动/3个非重叠起报，DM不得硬算显著。CI是逐比较区间，不冒称同时置信区间。

非重叠3d的时间块长度为1个起报，对应约3天；同时保存最差域MAPE差的配对bootstrap区间。不将“没有显著恶化”解释为已证明等效或非劣，尤其是独立节点少、区间覆盖较宽时。

风险AUROC/Brier/精确率/召回率及收益MAE另按目标域cluster bootstrap，不能将数万个专家配对当IID。节点在同一中心相关，9个M100目标、89个UCC目标都不等于这么多个独立中心；短测试日段的统计只支持这些条件下的效应，不支持中心总体显著性。

固定风险分箱[0,0.1,…,1]、固定收益分箱(-∞,-5,-1,-0.1,0,0.1,1,5,∞)，分别保存校准期曲线与新测试曲线，不用测试分位数择箱。建议门槛逐条报告通过/未通过/证据不足；不能因某项未通过而在本测试上改机制。

方法依据：[Diebold–Mariano原论文](https://doi.org/10.1080/07350015.1995.10524599)用于辅助预测损失比较，[Holm原论文](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)用于多重比较。块长度和循环重采样是本协议的固定设计；不将其误称为随机块长的[stationary bootstrap](https://doi.org/10.1080/01621459.1994.10476870)。

## 7. 复现与最终保留

每次真实运行创建新目录，保存完整配置/角色/原始哈希、全部适配契约及掩码、源内教师、收益训练表、校准数据/参数/曲线、验证候选、最终模型、全局冻结、各方向测试开始、预测/逐起报指标、源矩阵、路由、oracle分析、统计和保存恢复审计。共用评分与紧凑Parquet产物，避免按节点重复大量相同模型。

本轮在任何真实新误差访问前完成合成端到端测试、数据契约审计和预注册；真实结果只运行一套冻结方案。失败产物保留failed状态；若仅有评分/报告错误，应保留冻结模型重放修复，不据结果重新拟合。

Eagle整体封存，无观测、标签或用于设计的聚合读取。后续第三数据集、留一数据集元验证与最终Eagle研究另立协议。当前成果均为节点/服务器功率，设施总有功功率项目目标仍需独立设施表证据。
